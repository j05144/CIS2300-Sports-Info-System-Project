# CIS2300-Sports-Info-System-Project
CIS 2300 – Programming and Computational Thinking

## Overview
A menu-driven sports information database system built in Python using Jupyter Notebook. The program allows users to manage and explore sports data across multiple countries through an interactive command-line interface.

## What It Does
- View the full sports dataset with optional bar chart visualization
- Filter data by specific sports and countries
- Add new sports with custom scores
- Delete existing sports from the database
- Save all changes back to the CSV file
- Look up sports information using the Wikipedia API

## Technologies Used
- Python
- Pandas
- Matplotlib
- Wikipedia API
- Jupyter Notebook
